# 📊 Superstore Sales Analysis – Power BI Project

## 📝 Project Overview
This project analyzes the **Sample Superstore dataset** to uncover insights on sales, profit trends, and regional performance.  
The goal is to help management make **data-driven decisions** by identifying key growth areas and loss-making categories.

---

## 🛠 Tools & Skills Used
- **Power BI:** Data cleaning (Power Query), DAX measures, interactive dashboards
- **Excel:** Basic data validation and exploration
- **Data Analysis Skills:** EDA, KPI tracking, trend analysis

---

## 🔍 Problem Statement
The business needs to understand:
- Which products and categories contribute most to profit?
- Which regions underperform and need attention?
- How sales vary by month, segment, and shipping mode.

---

## 📊 Dashboard Highlights
- **KPIs:** Total Sales, Profit, Profit Margin, Orders
- **Visuals:** Bar charts, line charts, map of sales by region, filters/slicers
- **Interactivity:** Users can filter by year, region, and category
